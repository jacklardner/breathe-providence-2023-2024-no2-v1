# breathe-providence-2023-2024-no2-v1

This script acts to be a cleaned and reproducible workflow that can mainly is
meant to demonstrate how the 2023-2024 NO2 dataset was produced for the Breathe
Providence low cost air sensor network. Final and cleaned data folders can be
emptied (minus their folder structure, i.e. only files within them removed) and
the main notebook can be run to produce the final datasets.

Please see the attached PDF to describe the calibration process in more detail
and why certain design decisions were made in this calibration process.
